# EcoRecicla ♻️

Projeto de site sobre **reciclagem e sustentabilidade**, desenvolvido com **HTML5** e **Bootstrap 5**.

## 🌱 Objetivo

Conscientizar as pessoas sobre a importância da reciclagem e facilitar
- Incentivar a reciclagem
- Promover educação ambiental
- Facilitar o agendamento de coleta
- Divulgar serviços sustentáveis
- Criar um site simples e responsivo
o **agendamento de coleta de materiais recicláveis**.

## 📄 Páginas do Projeto

- Página Inicial (Home)
- Sobre Nós
- Nossos Serviços
- Saber Mais sobre Reciclagem
- Agendar Coleta

## 🛠️ Tecnologias Utilizadas

- HTML5   
- Bootstrap 5.3 
- JavaScript (Bootstrap)

## 📱 Responsividade

O site é totalmente responsivo, funcionando bem em:
- Computadores
- Tablets
- Celulares

## 🌍 Impacto Social

O EcoRecicla busca contribuir para:
- Redução do lixo
- Preservação ambiental
- Conscientização da sociedade
- Promoção da sustentabilidade

## 🎨 Layout e Design

- Design limpo e moderno
- Cores inspiradas na natureza
- Uso de cards, botões e sombras
- Navegação simples e intuitiva

## Como Executar

1. Baixe ou clone o projeto
2. Abra o arquivo `index.html` no navegador
3. Não é necessário servidor
